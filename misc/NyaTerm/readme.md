# NyaTerm

官方描述：
```
NyaTerm 是一个基于 GPUI 构建的现代原生远程终端工作区。
在一个桌面客户端中处理 SSH、本地 Shell、Telnet、串口、RDP、VNC、SFTP、隧道、OTP、AI 辅助与加密同步。
```
