# ServerKit

ServerKit是一款轻量、现代的服务器控制面板，用于管理 Web 应用、数据库、 Docker 容器和安全策略。

github地址: https://github.com/jhd3197/ServerKit

扩展 Malware Scanner
```
ClamAV + YARA malware scanning for ServerKit: quick/full/custom-path scans, job-backed app docroot scans with a curated web-shell rule pass, custom .yar rules, scan history, and a quarantine with restore. ClamAV installs on demand from the page; the YARA pass works everywhere via a pure-Python fallback.
```
