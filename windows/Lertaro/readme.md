# Lertaro

Windows搜索、启动、磁盘空间分析工具

github地址: https://github.com/Lertaro/Lertaro  
用户手册: https://lertaro.github.io/zh-CN/user-guide/

## 一些快捷键
- `双击Ctrl` 打开简易搜索面板
- `简易搜索面板 Ctrl + F` 打开完整搜索面板

## 一些符号
- `!` 排除
- `'` 精确
- `^` 前缀
- `$` 后缀
- `|` 或条件
- `#` 管理员执行命令
- `$` 普通用户执行命令

## 自定义命令
- 入口: `设置 → 插件 → 自定义命令 → 配置`
- 作用: 把命令行工具、脚本或外部应用包装成一条短命令
- 触发: 与其它关键词插件一致，输入 `触发词 + 空格 + 参数` 调用（关键词后可跟任意输入）

参考: https://lertaro.github.io/zh-CN/user-guide/instant-answers.html#_6-自定义命令
